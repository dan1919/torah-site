# חידושי הדעת

אתר סטטי המציג את דברי התורה והחידושים של **דן עוגן**.

## מבנה האתר

- **פרשות השבוע** – כל הפרשות שיש עליהן חידושים
- **מועדים** – ראש השנה, פורים, פסח, חנוכה ועוד
- **דברים כלליים** – חידושים שאינם משויכים לפרשה או מועד ספציפי

יש חיפוש חופשי + ניווט נוח (במובייל נפתח מתפריט).

## העלאה ל-GitHub Pages

1. צור ריפוזיטורי חדש ב-GitHub.
2. העלה את הקבצים `index.html` ו-`data.js` לשורש הריפו.
3. היכנס ל־**Settings → Pages**.
4. ב־Source בחר: Deploy from a branch → `main` → `/ (root)`.
5. האתר יהיה זמין בכתובת:  
   `https://<your-username>.github.io/<repo-name>/`
